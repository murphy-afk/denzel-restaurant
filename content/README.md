# Denzel Content Directory

Extracted content from https://www.denzel.it/ for the redesign project.

## Structure

- copy/pages.md: All Italian page copy consolidated in one file
- data/menu-ita.json: Full structured Italian menu (categories, items, prices)
- data/menu-images.json: Map of all 48 menu photo files (4 languages x 12 images)
- data/gallery-images.json: Map of all 28 gallery photos with captions
- data/reviews.json: Press reviews for the Dicono di noi page with sources
- notes/style-notes.md: Visual style analysis (colors, typography, vibe)
- images/menu/ita/ | eng/ | ebr/ | fra/: Downloaded menu photos
- images/gallery/: Downloaded gallery photos
- images/assets/ : Logo, hero, card, and page photos
- html/: Raw page HTML and Wix API responses used for extraction

## Key facts

- Restaurant: Denzel, kosher gourmet street food, Via Washington 9, Milano
- Menu exists only as photos on the source site; transcribed into menu-ita.json
- Menu has 4 language versions (Italian, English, Hebrew, French), 12 images each
- Visual style: dark chalkboard background, green accent (#3CB44A), chalk-style titles
- Reviews are from Italian food press (Corriere, Dissapore, and others)
